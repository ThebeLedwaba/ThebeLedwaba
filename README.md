## About Me

Software engineer holding **AZ-204**, **AZ-900** and **CCNA** certifications, completing my Advanced Diploma in **Computer Systems Engineering** in 2026. I build full-stack applications, deploy them on Azure with containers and CI/CD pipelines, and work with embedded hardware at the edge.

At **Scaw Metals Group**, I built and deployed an industrial IoT telemetry platform monitoring 500+ production assets (ESP32, MQTT, REST APIs, MariaDB). I also co-founded **AuraRent**, a live PropTech SaaS platform processing real tenant payments through Paystack, where I own the cloud architecture and deployment.

My low-level background, including **ThebeRTOS**, a preemptive RTOS kernel I wrote from scratch in C and AVR Assembly, means I'm comfortable debugging below the application layer and thinking about performance and failure modes in the systems I build.

**Certifications:** Azure Developer Associate (AZ-204) · Azure Fundamentals (AZ-900) · Cisco CCNA (1–3)

## Featured Projects

### [AuraRent](https://github.com/ThebeLedwaba/AuraRent) — *PropTech SaaS Platform (Co-Founder & Lead Architect)*
- Architected and deployed a multi-tenant rental management system processing live tenant transactions via Paystack.
- Built automated financial ledger tracking and role-based access control, with containerised deployment, using TypeScript, React, Node.js and PostgreSQL.

### Industrial IoT Asset Telemetry Platform — *Scaw Metals Group (Production Deployment)*
- Built and deployed a real-time monitoring pipeline covering 500+ industrial production assets across the plant floor.
- Integrated ESP32 edge nodes over MQTT into containerised REST APIs, with automated deployment workflows.

### [CI-CD-node.js-App](https://github.com/ThebeLedwaba/CI-CD-node.js-App) — *Automated Build & Deployment Pipeline*
- Configured GitHub Actions workflows for automated linting, unit testing, dependency caching and containerised image builds on every push.
- Implemented secret management and automated release steps to streamline cloud deployments.

### [Smart Agricultural Hydroponics Automation System](https://github.com/ThebeLedwaba/Smart-Hydroponics-Automation-System) — *Edge-to-Cloud IoT*
- Built a closed-loop monitoring and control system (`ESP32 → MQTT → Express.js → React` & `MariaDB`) with custom KiCad hardware schematics.
- Implemented bidirectional actuator state synchronisation and a local SQLite WAL fallback to prevent telemetry loss during network outages.

### [ThebeRTOS-AVR](https://github.com/ThebeLedwaba/ThebeRTOS-AVR) — *Preemptive Real-Time Operating System Kernel*
- Built a priority-based preemptive scheduler from scratch in C and AVR Assembly for the ATmega328P (`2KB SRAM`).
- Implemented priority-inheritance mutexes, counting semaphores, stack-canary overflow detection and a zero-heap-allocation memory model.

### [SkillMap ZA](https://github.com/ThebeLedwaba/SkillMap-ZA) — *NLP Job Market & Skill Cluster Analyzer*
- Built an end-to-end ML analytics pipeline (`TF-IDF → KMeans Clustering → PCA`) with Python, scikit-learn and a React dashboard to map tech skill demand across South Africa.
